Where do I find my token?
  1. Open discord.com/app and sign in normally.
  2. Press F12, open the Network tab, then reload with F5.
  3. Filter by Fetch/XHR and click any request to /api/v9/users/@me.
  4. Under Request Headers, find authorization and copy its whole value — that value is the token itself, with no prefix.
  5. Paste it above, or drop it in a .txt file and use Choose .txt.

Only ever do this with your own account. A token is a password — anyone who obtains one can sign in as you, with no second check.
