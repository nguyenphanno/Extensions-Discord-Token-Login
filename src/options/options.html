    Vault

    Tokens are encrypted with AES-256-GCM before they touch disk. This section decides where the encryption key lives.

    Device key

    A random 256-bit key is generated once and kept in this browser's extension storage.

    Convenient, and it protects against a copied profile, a synced backup, or anyone casually opening devtools. It does not protect against code already running on your machine. Add a passphrase if that matters to you.

    Passphrase

    Derived with PBKDF2-SHA256 at 310,000 iterations and never written to disk. You unlock once per browser session.

    Every saved token is re-encrypted under the new key. If you forget this passphrase, the tokens cannot be recovered by anyone, including you.

    Behaviour

    Preferences are stored in plain text. None of them are secret.
